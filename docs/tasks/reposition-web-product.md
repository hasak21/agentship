# Reposition the web product around verification

## Objective

Make the visible product language match AgentShip Verify's evidence-based preflight positioning while retaining the model lab as an explicitly experimental surface.

## Requirements

1. The page title and header identify AgentShip Verify and its evidence-based purpose.
2. Preflight diff is the default web workflow.
3. Navigation uses preflight, evidence, and run-history language.
4. Audit navigation displays PASS or BLOCK rather than a decorative numerical score.
5. Model topology features are labeled experimental and do not imply trusted evidence.
6. README and integration language reflect the same product hierarchy.
